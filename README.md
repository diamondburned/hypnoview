# hypnogaze

<details>
<summary>This project is pretty promiscuous! (This means it's 18+).</summary>

---

Hypnogaze provides a Go client library for the [Hypnohub](https://hypnohub.net)
image board, a rolling 2-hour SQLite popularity indexer, a Huma OpenAPI REST
API, and a mobile-friendly web frontend (`cmd/hypnogaze`) hosted at [gaze.d14.pet](https://gaze.d14.pet).

See [docs/rolling-index-design.md](./docs/rolling-index-design.md) for the
v2 rolling popularity index and frontend architecture.

</details>
